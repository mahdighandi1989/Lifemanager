# به‌روزرسانی وابستگی‌های Python در requirements.txt

## Raw Idea

فایل requirements.txt شامل وابستگی‌هایی با نسخه‌های مشخص است که ممکن است با یکدیگر ناسازگار باشند. به طور خاص، پکیج passlib با نسخه 1.7.4 با bcrypt نسخه 4.1+ ناسازگار است و نیاز به pin کردن bcrypt زیر 4.1 دارد. همچنین، پکیج pydantic دو بار با نسخه‌های مختلف ذکر شده است (pydantic==2.10.4 و pydantic[email]==2.10.4) که ممکن است باعث سردرگمی در نصب شود. این ناسازگاری‌ها می‌توانند منجر به خطاهای runtime یا عدم نصب صحیح وابستگی‌ها شوند.
