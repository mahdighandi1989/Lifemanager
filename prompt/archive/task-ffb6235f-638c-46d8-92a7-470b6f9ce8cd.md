# Fix SQL injection in dynamic query building

## Raw Idea

The project search functionality builds SQL queries using string formatting with user input. This creates a SQL injection vulnerability that can be exploited to read, modify, or delete database records.

## Prompt

## ⚠️ یادداشت مهم برای مدل اجراکننده — قبل از شروع بخوان

این پرامپت بر اساس یک **بررسی اولیهٔ خودکار** از repo ساخته شده — ممکن است
حاوی اشتباه، تشخیص نادرست، یا حذف موارد مهم باشد. به‌عنوان منبع نهایی به
آن استناد نکن.

- ممکن است **بخشی یا تمامِ** این درخواست قبلاً (به صورت کامل یا ناقص) در
  repo پیاده‌سازی شده باشد. پیش از شروع، با grep/search و خواندن فایل‌های
  مرتبط بررسی کن که چه چیزی **از قبل وجود دارد**.
- اگر یک قابلیت/فایل/تابع از قبل موجود است: آن را **دوباره نساز**؛ فقط

## 🪜 مراحل اجرایی پیشنهادی
1. Replace string formatting with parameterized queries using SQLAlchemy's ORM methods or raw SQL with bind parameters.

## 💡 نمونه‌های قبل/بعد
**Use parameterized query**

_قبل:_
```
query = f"SELECT * FROM tasks WHERE title LIKE '%{user_input}%'"
```

_بعد:_
```
query = text("SELECT * FROM tasks WHERE title LIKE :pattern")
result = db.execute(query, {"pattern": f"%{user_input}%"})
```
