# Secure and retry outgoing webhooks

## Raw Idea

The integration service at app/services/integration_service.py and webhook route at app/routes/webhook.py show no evidence of webhook signature verification. Without verifying that incoming webhooks are from trusted sources, the system is vulnerable to spoofed webhook attacks. Additionally, there's no retry mechanism for failed outgoing webhook deliveries.

## ✅ معیار پذیرش (Acceptance Criteria) — رفتار-محور

- [ ] Webhooks without valid signature return 401
- [ ] Webhook signature verification uses SHA256 HMAC
- [ ] Failed outgoing webhooks are retried 3 times with backoff
- [ ] Webhook delivery attempts are logged with timestamps
- [ ] هیچ تستی fail نمی‌شود (`npm run test` / `pytest`)
- [ ] linter بدون warning عبور می‌کند
- [ ] type-check موفق است (`tsc --noEmit` / `mypy`)

## 🪜 مراحل اجرایی پیشنهادی
1. Implement HMAC signature verification for incoming webhooks using shared secrets. Add webhook delivery retry logic with exponential backoff for outgoing webhooks. Store webhook delivery attempts and status in the database.

## 💡 نمونه‌های قبل/بعد
**Add webhook signature verification**

_قبل:_
```
async def handle_webhook(provider, payload):
    await integration_service.process_webhook(provider, payload)
```

_بعد:_
```
async def handle_webhook(provider, payload, signature: str = Header(None)):
    secret = await get_provider_secret(provider)
    if not verify_signature(payload, signature, secret):
        raise HTTPException(401, 'Invalid signature')
    await integration_service.process_webhook(provider, payload)
```
