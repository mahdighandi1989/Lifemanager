## 💡 نمونه‌های قبل/بعد
**hashing رمز عبور با bcrypt**

_قبل:_
```
user = User(password=data['password'])
```

_بعد:_
```
hashed_password = bcrypt.hashpw(data['password'].encode(), bcrypt.gensalt())
user = User(password=hashed_password.decode())
```
