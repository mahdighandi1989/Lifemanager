# Genericize Registration Errors to Prevent Enumeration

## Raw Idea

## 📋 شرح ناسازگاری
در pipeline `auth` یک ناسازگاری منطقی پیدا شد:

The `app/services/auth_service.py` lists `ValueError (for ..., existing email/username, ...)` as an expected output during user registration. Explicitly informing a user that an email or username already exists allows an attacker to enumerate valid user accounts by trying common email addresses or usernames.

## 💥 پیامد (impact)
An attacker can build a list of valid user accounts, which can then be used for targeted phishing attacks, brute-force password attempts, or social engineering. This compromises user privacy and increases the attack surface.

## 🛠 پیشنهاد رفع اولیه
For registration, return a generic error message (e.g., 'Registration failed, please check your input') regardless of whether the email/username is already taken or if other validation errors occurred. Alternatively, if specific feedback is desired, implement rate limiting on registration attempts to mitigate enumeration.
