# TO-DO — genuinely external / blocked residuals

This folder records the **small** set of task residuals that cannot be built in
the repo alone because they depend on external credentials, paid third-party
services, or physical hardware. Everything that is buildable in-repo is built —
this folder is **not** a dumping ground for deferred work, only for items that
are blocked on something only the repo owner can supply.

Each file is named `task-<id>-<slug>.md` and states: what's blocked, why, and
exactly what to do once the external dependency is available (the code seams are
already in place so wiring is mechanical).
