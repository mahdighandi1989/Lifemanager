# Grounding confidence numbers in axioms

## 🎯 چالش / Challenge
یک موتورِ قاعده‌محور به هر نوع استدلال «سقفِ اطمینان» می‌داد (۹۵/۸۰/۷۰/۴۵/۲۵ و تحملِ ۱۰) و صاحب‌کار پرسید «این عدد بر چه مبنایی است؟».
جوابِ صادقانه: قرارداد. راهِ آسان، برازشِ عددها روی پیکرهٔ آزمون، خودش استقرا است — و پیکره‌ای که برای آزمودنِ قاعده‌ها از شکست‌ها
گزینش شده، نسبتِ درستیِ واقعی را اصلاً نمی‌دهد (سوگیریِ گزینش).

## 💡 راه‌حل / Solution
1. **اصول را از خودِ متنِ مرجع بگیر** (این‌جا: «کل از جزء بزرگ‌تر است»، امتناعِ تناقض، بازهٔ ۰..۱، حسابِ احتمالات که متن صریحاً نام می‌برد، امتناعِ ترجیحِ بلامرجح).
2. **هر عدد را به قضیه برگردان** و برهان بنویس: تعارض با یقینی ⇒ ۰؛ شرطِ احرازنشده ⇒ ≤ ½ (تقارن)؛ زنجیره ≤ ضعیف‌ترین حلقه؛ مستقل‌ها ⇒ ضرب؛
   موردِ بعدی پس از n موافق ⇒ (n+1)/(n+2)؛ حکمِ کلی بر دامنهٔ نامحدود از شمارشِ محدود ⇒ نزدیک به صفر؛ راهِ غیرِ برهانی ⇒ < ۱.
3. **هر سقف را طبقه‌بندی کن:** B (عدد = قضیه)، S (ساختار = قضیه، مقدارِ پایه تجربی)، O (فقط نابرابری)، X (ناسازگار با قضیه ⇒ پیشنهاد).
4. **پایه‌ها را فقط با نمونهٔ بی‌گزینش و کافی بسنج** (گروهِ مستقل، بازهٔ ویلسون با آستانهٔ پهنا)؛ وگرنه «ناکافی» و هیچ عدد. قضیه بر سنجش مقدم است (سنجیده ≤ کران).
5. **اثرِ هر جایگزینی را روی کلِ پیکره در حافظه بسنج** با گزینه‌های پیش‌فرض‌خاموش؛ تغییرِ واقعی فقط با تصمیمِ صاحب‌کار.

function measure(cases, select) {                 // only unselected samples, one vote per independent group
  const g = {}; cases.filter(c => c.sample === "unselected").forEach(c => c.claims.forEach(k => {
    if (matches(select, k.f) && !(c.grp in g)) g[c.grp] = k.truth; }));
  const n = Object.keys(g).length, w = wilson(Object.values(g).filter(Boolean).length, n);
  return n >= 30 && w.hw <= 0.10 ? Math.min(99.9, 100 * w.p) : null;   // null = "not measured"
}

## ⚠️ نکات حیاتی / Pitfalls
- رفتن فقط با درجه‌های کیفی (یقین/ظن/شک/وهم) ساده و «بی‌قرارداد» به نظر می‌رسد ولی اطلاعات را دور می‌ریزد: این‌جا ۱۰ شکستِ واقعیِ دیده‌شده از دست می‌رفت. یعنی آن عددها اطلاعات داشتند ولی مبنا نه — راهش سنجشِ پایه است، نه حذف.
- با کرانِ قضیه چند شرط هم‌سقف می‌شوند؛ اگر فقط «اولین» را مقصر بدانی، مکان‌یابی به ترتیبِ قاعده‌ها بسته می‌شود — همه را پرچم بزن.
- عددِ «سخت‌گیرتر از قضیه» (۲۵ به‌جای ≤ ½) هم قرارداد است: «وهم» یعنی ترجیح به سودِ نقیض، که دلیل می‌خواهد.
- «استقراءِ ناقص» دو گزارهٔ متفاوت است (حکمِ کلی ↔ موردِ بعدی) با دو جوابِ متفاوت؛ بی ویژگیِ «گسترهٔ ادعا» هیچ عددِ ثابتی درست نیست.

## 🔁 چطور در جای دیگر اعمال کنیم / How to Apply Elsewhere
هر جا امتیاز/وزن/آستانه‌ای «تجربی» گذاشته شده (ریسک، اعتبارسنجی، اولویت، فیلترِ هشدار): (۱) اصولِ پذیرفتهٔ دامنه را صریح کن؛ (۲) هر عدد را
B/S/O/X کن؛ (۳) فقط پایه‌های S را بسنج، با نمونهٔ بی‌گزینش و آستانهٔ کفایت؛ (۴) جایگزینی را پیش‌فرض‌خاموش و با اثرِ سنجیده پیشنهاد کن.

## Update 2026-10-13
- **سقفِ فرمولی:** وقتی قضیه عدد را از ویژگی‌های همان مورد می‌سازد (مثلاً (n+1)/(n+2))، سقف را تابعی از ویژگی‌ها کن (`capf`)، نه یک عددِ نماینده؛ و ویژگیِ لازم (این‌جا «گسترهٔ ادعا») را با **رمزگذارِ کور** پر کن.
- **هر کرانِ گذشته‌شده یک دلیلِ مستقل است:** فقط کمینه را مقصر دانستن مکان‌یابی را به اندازهٔ نسبیِ سقف‌ها می‌بندد؛ با کرانِ قضیه‌ای همهٔ گذشته‌شده‌ها را پرچم بزن (این‌جا مکان‌یابیِ کامل ۹۰ ⇒ ۱۰۱).
- **نتیجهٔ درست با دلیلِ نادرست:** قضیه‌ای‌شدن پرونده‌ای را که با عددِ قراردادی «درست» بود شکست (جوجهٔ راسل: شمار توجیه می‌کند؛ خطا در علت است). پنهانش نکن — یافته + پیشنهاد.
- قاعدهٔ قدیم را حذف نکن؛ «گذرا» کن (فقط برای موردهای بی‌ویژگیِ تازه) تا داده‌ی رمزگذاری‌نشده بی‌سقف نماند.

## Update 2026-10-14
- **پیش از اعلامِ «تناقضِ منبع»، هر دو طرف را با لفظِ خودِ منبع (و پانوشت‌هایش) بسنج.** این‌جا یک طرفِ «تناقض» برداشتِ خودمان بود که در متنِ قاعده نوشته شده بود؛ و عددی که خودِ پرونده «تقریبِ سامانه» می‌نامید، شاهد شمرده شده بود. هر نقلِ داخلِ گیومه در قاعده‌ها باید لفظِ منبع باشد، نه خلاصهٔ ما.

## Update 2026-10-14 (b)
- **هیچ عددی بیرون از سه گونه:** قضیه؛ قضیه × دادهٔ احرازشده؛ «نمی‌دانیم = ½». آستانه‌های «کفایت» و «تحمل» هم عددند و قراردادی بودند — برداشته شدند؛ قضیهٔ (k+1)/(n+2) کم‌داده بودن را خودش نزدیکِ ½ نگه می‌دارد.
- **خودبهبودیِ امن:** فقط مقدارهای پایه خودکار حرکت می‌کنند، و فقط از «قاب»های معتبر (از پیش معین، همه‌اش، هر مورد احرازشده)؛ هر حرکت با شاهد در دفتر. قاعده/قضیهٔ تازه با تصمیمِ صاحب‌کار؛ اصلِ تازه هرگز به دستِ عامل.
- **نگهبانِ قطعی** (`audit` + سلامتِ دور) جلوی «کم‌کاری» و «دور شدن از مبنا» را می‌گیرد؛ به حسنِ نیتِ عامل تکیه نکن.
