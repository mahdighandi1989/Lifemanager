# همراهِ رصدگر — Lifemanager Companion (Android)

نسخهٔ همیشه‌زندهٔ موبایلیِ همین پروژه: روی هر گوشی اندرویدی نصب می‌شود و
**بدون هیچ کار دستی** این‌ها را به برنامهٔ اصلی می‌فرستد:

| چه چیزی | به کجا می‌رود | چه می‌شود |
|---|---|---|
| هر SMS (مخصوصاً پیامک بانک‌ها) | `POST /api/mobile/sms` | لاگ فعالیت + اگر بانکی باشد از **همان موتور سخت‌گیر مالی** رد می‌شود و موجودی کارتِ درست را به‌روز می‌کند (تکراری‌ها خودکار حذف؛ ارزِ غلط رد) |
| هر اعلان (نوتیفیکیشن) گوشی | `POST /api/mobile/notification` | لاگ فعالیت + اعلان‌های اپ بانک هم مثل SMS به مالی می‌رسند |
| کارکرد روزانهٔ اپ‌ها | `POST /api/mobile/usage` | یک ردیف خودشناسی در لاگ فعالیت («امروز چقدر کجا بودم») |
| ضربان («زنده‌ام») | `POST /api/mobile/heartbeat` | وضعیت گوشی در `/api/mobile/status` و نبضِ کارت mobile در «دیاگرام زنده» |

## نصب (یک بار برای هر گوشی — بدون هیچ ابزار برنامه‌نویسی)

فایل نصبی (APK) را **سرورهای GitHub خودکار می‌سازند** (workflow:
`.github/workflows/build-companion-apk.yml`) و داخل خود برنامه قرار می‌گیرد:

1. روی گوشی اندرویدی، در مرورگر این آدرس را باز کن:
   **`آدرس-سایتت/companion.apk`** (مثلاً `https://<your-app>.onrender.com/companion.apk`)
   — دانلود شروع می‌شود. (راه پشتیبان: صفحهٔ Releases همین ریپو در GitHub،
   نسخهٔ «companion-apk».)
2. فایل دانلودشده را لمس کن → اگر پرسید، «نصب از منابع ناشناس» را برای مرورگر
   اجازه بده → نصب.
3. در برنامهٔ وب (وقتی وارد شده‌ای) آدرس `/api/mobile/token` را باز کن — یک
   token می‌گیری.
4. اپ «همراه مدیریت زندگی» را باز کن: آدرس سایت + token + نام گوشی را وارد و
   «اتصال و شروع رصد» را بزن.
5. با دو دکمهٔ داخل اپ، دسترسی «اعلان‌ها» و «آمار مصرف» را هم بده. تمام —
   از این لحظه گوشی خودش گزارش می‌دهد (در برنامهٔ وب: `/api/mobile/status`).

> برای برنامه‌نویس: همین پوشه یک پروژهٔ استاندارد Gradle است و در Android
> Studio هم با `Build → Build APK(s)` ساخته می‌شود.

## نکته‌های صادقانه

- **آیفون نمی‌تواند SMS بخواند** — سیاست اپل است، نه محدودیت ما. روی آیفون همان
  PWA (نسخهٔ وب نصب‌شدنی) را داشته باش؛ SMSخوانی فقط روی اندروید ممکن است.
- این اپ فقط به سرورِ **خودت** می‌فرستد (آدرسی که خودت وارد می‌کنی، با tokenِ
  خودت). هیچ سرویس واسطه‌ای در کار نیست.
- Google Play اپ‌های SMSخوان را سخت می‌پذیرد — این اپ برای نصب شخصی (sideload)
  طراحی شده و نیازی به استور ندارد.
- این سورس در محیط توسعهٔ فعلی **کامپایل نشده** (SDK اندروید این‌جا نیست)؛
  ساختار پروژه استاندارد Gradle است و در Android Studio ساخته می‌شود.
  سمتِ سرور (endpointها) کاملاً تست‌شده و روی برنامه زنده است.

## نکتهٔ امضا (2026-07-31)

همهٔ buildها با یک کلید ثابت (`signing/companion.keystore`) امضا می‌شوند تا
به‌روزرسانی روی نسخهٔ نصب‌شده همیشه مجاز باشد. دو build اول CI با کلید
یک‌بارمصرف امضا شده بودند — اگر یکی از آن‌ها را نصب کرده‌ای، **یک بار** آن را
Uninstall کن و نسخهٔ تازه را نصب کن (آدرس/توکن را همان یک بار دوباره وارد
می‌کنی)؛ از آن به بعد همهٔ به‌روزرسانی‌ها بدون حذف نصب می‌شوند. این کلید فقط
اعتبار «به‌روزرسانیِ sideload شخصی» دارد و ارزش امنیتی فروشگاهی ندارد.
