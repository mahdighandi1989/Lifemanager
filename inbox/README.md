# inbox/ — owner drop zone

Drop material here for review: exported data to import, AI-assisted reports, screenshots,
logs, CSV/JSON dumps. Modeled on the trading-system repo's `inbox/`.

- **Contents are ephemeral and gitignored** (safe to delete after review). This README is the
  only tracked file, so the folder structure persists.
- After reviewing something here:
  - a reusable lesson → `experiences/` (merge, don't replace);
  - a durable report → `docs/decisions/`;
  - actual data to load → use the **Import** page / `/api/imports` flow.
- Log what you did with each item in `docs/overhaul/AUDIT_LOG.md`.
