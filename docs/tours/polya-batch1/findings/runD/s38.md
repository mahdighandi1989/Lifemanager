## Success criteria
- [PASS] The first hint comes after hearing the user's effort and is phrased as a list question. p1 asked «تا حالا چه کرده‌ای…؟» (no answer, no sermon: «جوابِ خالی فردا سرِ کلاس کمکت نمی‌کند… طول نمی‌کشد»). After her effort (s1), p2: «به مجهول نگاه کن — حجم… می‌توانی این چهاروجهی را به دو تکهٔ ساده‌تر بشکنی…؟».
- [PASS] The hint ladder has at least two rungs. Problem 1: rung 1 (p2), rung 2 (p3: «صفحه‌ای… که از یکی از دو یالِ a و از پاره‌خطِ b می‌گذرد…»), and she solves it (s3). Problem 2: three rungs (p6–p8).
- [PASS] A next-day follow-up is scheduled and independent reconstruction is requested. tutor_mark(back) created card «بازنگری — «حجمِ چهاروجهی»: بی‌نگاه دوباره حلش کن…», due 2026-10-16 (s4). On 2026-10-16 «امروز» listed «۳ کارت مرور موعد امروز» and she reconstructed without looking (s5). Caveat: the only push reminder at 16:00 was the deadline reminder (see defects).
- [PASS] If the last rung also fails, the system gives the solution with the key idea isolated (not abandonment). Problem 2, p9: «راه‌حل: … ایدهٔ کلیدی فقط این است: «زاویهٔ خارجی = مقدارِ پیچ، و یک دورِ کامل = ۳۶۰». حالا صفحه را ببند و خودت با کلماتِ خودت بنویسش؛ فردا یک کارتِ مرور می‌آید…». Card due 2026-10-17. Caveat: the model had to override the prompt here (see S2).

Failure signatures:
- (a) "Never answer" as an absolute rule: the prompt text leans that way. The model avoided it only by judgement.
- (a) Answering under pressure: not seen.
- (b) No scheduled follow-up: not seen.
- (c) Next-day reminder in the wrong timezone: the harness browser runs in UTC, so tz:"UTC". Real code uses Intl.resolvedOptions(), so this is not a defect. A different reminder-timing problem is listed below.

## Defects
- [S2] (b) The assistant prompt has no "end of the hint ladder" rule (Pólya: help neither too much nor too little; after serious effort and a failed last hint, show the solution with the key idea isolated, then have the student redo it). It says the opposite:
  - sys: «جوابِ مسئله را نگو؛ کاربر را تا خودِ حل ببر»;
  - the tutor hook: «اگر جواب خواست، یک پله کلی‌تر بپرس؛ فقط پس از تلاشِ خودش یک پله خاص‌تر».
  A model that follows the prompt literally would leave a student stuck after 1.5 h and three hints. That is the pedantry failure signature. There is also no record of «ایدهٔ کلیدی» or a forced "close the book and redo".
- [S3] (b) Deadline reminders are date-only. For «فردا ۸ صبح» the only push is on the deadline day at the default 9:00, after the deadline. remind_hour(16), meant for the follow-up, moved that same deadline reminder to 16:00, so the 16:00 push read «تحویلِ تکلیفِ هندسه… (امروز)» instead of «بازسازیِ بی‌نگاه». Review cards have no push of their own.
- [S3] (c) After the user said she had delivered the homework, «امروز» still showed «⏰ تحویلِ تکلیفِ هندسه… موعد: امروز». The assistant has no action to mark a deadline done.

## Summary
Short honest refusal, effort first, a two-rung ladder, solved by herself, key idea isolated, next-day no-look card done. A second problem confirmed the model can reveal the solution with the key idea after the last rung, but the prompt literally forbids it. No sheets, tour or e-mail. All four criteria passed by execution.

RESULT: PASS (with one S2 prompt-design defect)
