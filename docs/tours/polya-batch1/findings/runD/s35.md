# s35 — اجتماعی/محله: تفکیکِ زباله‌ای که دو بار ول شد (آقای نوری، ضرب‌المثل‌گو)

Harness: camp/harness3.js on dist (not rebuilt). I played the user and the page's model (8 AI calls).
Clock (tools/day.py): sessions at day 1, +2, +12 and +50 (month 2).
Path:
- Chat: despairing proverb plus «همین هفته طرحِ سوم».
- The model asks why the two attempts failed before any plan. The user analyses: irregular collection, no reminders, he follows up alone.
- «🔭» live problem «ماندگاریِ تفکیکِ زبالهٔ محله». The understanding card has the failure causes as data and the unknown as «ماندن، نه شروع».
- Session 2: the neighbouring district ولیعصر is used as the related solved problem («همین مجهول را جایی دیده‌ای» plus plan heuristic «مسئلهٔ مرتبط»). Plan saved; step 1 with forecast.
- Session 3: the user wants to swap two alternatives weekly; the model warns about losing the goal.
- Month 2: outcomes recorded, «✅ حل شد», look-back question about other neighbourhood problems.

## Success criteria
- [PARTIAL] The system uses at least three proverbs/sayings fitted to different phases, and states their limits. Executed, model only:
  - s1 (understanding): limit of the user's «آب که از سر گذشت…» — «آن مَثَل برای وقتی است که دیگر کاری از دست برنمی‌آید»;
  - p2 (before the plan): «کار از محکم‌کاری عیب نمی‌کند» against his haste;
  - p7 (execution): «دو کمان داشتن خوب است، ولی اگر هر هفته عوض کنید… هدف را گم نکنید»;
  - p8 (look-back): «نگاهِ دوباره… اغلب از نگاهِ اول بهتر است».
  Neither the page nor the assistant prompt has any proverb or "wisdom of proverbs" knowledge (grep «ضرب‌المثل» in src finds 0). The live hook gives no stage-matched heuristic saying. As the page's model I mirrored the user's style; another model may not. This is not a page behaviour → PARTIAL.
- [PASS] The user analyses the earlier failures before plan 3. p1 asked «دقیقاً چه شد که هر دو بار بعد از یک ماه ول شد؟». User (s1): «سطل‌ها رو دادیم ولی کسی نیومد ببره… بار دوم… کسی یادآوری نکرد… من تنهایی نمی‌تونم». These were recorded as separate data d1–d3 on the 🔭 understanding card, with the unknown «ماندن، نه شروع» (s2), before any plan.
- [PASS] The neighbouring district is used as a "related solved problem". p5 hook suggested «آیا پیش‌تر آن را دیده‌ای؟». The user recorded it in «همین مجهول را جایی دیده‌ای» → «محلهٔ ولیعصر: پیمانکار بازیافت هفته‌ای سه بار و سفیر کوچه؛ روششون رو برای جمع‌آوری و یادآوری میارم». The plan gate showed «ابزارِ طرح که به کار بردی: مسئلهٔ مرتبط». The auxiliary element (a messaging group per alley) was named by the user (s4).

Failure signatures:
- (a) Proverbs treated as definite rules or ignored: not seen (model).
- (b) Proverbs decorative and unrelated to the phase: not seen.
- (c) The user's Turkish/Persian proverbs misread as commands: not seen. «"دو تا کمون داشته باش" دیگه!» did not trigger any action.

## What worked (+)
+ The live tunnel turned "past failures" into named data, and the unused-data gate made the plan account for each one.
+ The related-problem field and the heuristic gate («مسئلهٔ مرتبط») record the neighbouring district explicitly.
+ Forecasts and outcomes for real steps, and a solved state leading to the look-back card.

## Defects
- [S3] (b) Pólya's "wisdom of proverbs" (proverbs as vivid heuristic advice, each with an opposite proverb, not authoritative) is absent from the page and the prompt. For a proverb-speaking user, stage-matched sayings with their limits depend entirely on the model.
- [S3] (c) The unused-data check gives a false negative on paraphrase. The plan said «برای یادآوری و پیگیری… سفیر و گروه پیام‌رسان», but d2 «بار دوم: کسی یادآوری نکرد، مردم خسته شدن» was still listed as unused (fewer than half its words matched), so the user had to justify it (s7–s8). It is not harmful, but it is friction.
- [S3] (b) Goal drift from swapping two alternatives every week is not detected by the page (no check that a step is held long enough to test "ماندن"). Only the model caught it.

## Summary
Failure analysis before planning, a 🔭 live problem with the causes as data, the neighbouring district as the related problem, a warning against weekly swapping, two months sustained, solved, and a look-back. No sheets or tour; no e-mail. Two criteria passed. The proverb criterion was met only by the model's own style; there is no page support.

RESULT: FAIL (1 PARTIAL: proverb wisdom not supported by page or prompt)
