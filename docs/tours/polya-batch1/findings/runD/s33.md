## What worked (+)
+ The live hook's «داده‌هایی که هنوز به کار نرفته‌اند (… یکی را با نامش بپرس)» is exactly Pólya's «همهٔ فرض را به کار بردی؟», driven by the user's own data list.
+ The plan gate requires a real heuristic. «فقط بخشی از شرط را نگه دار» exists as an auxiliary-problem type with «از آن چطور به مسئلهٔ اصلی برمی‌گردی؟».
+ The next-day review card asks for the conclusion of a pod problem from memory («حکمی که باید درستی یا نادرستی‌اش را نشان بدهی…»).

## Defects

  - «۴) بخش‌های فرض — هر کدام جدا (چیزی که می‌دانی یا در دست داری: عدد، منبع…)» and «۵) بخش‌های فرض را جدا بنویس» both say hypothesis, for two different fields (data list vs. condition);
  - «۶) پیوندِ جزءها: کدام داده به کدام بخشِ شرط یا به مجهول…» and the intro «مجهول، هر داده جدا، و شرط» still use find-problem words.
  For a proof problem the user does not know where the clause's «فرض» goes.

There is no explicit "compare the claimed conclusion with the rule's conclusion" prompt.
