## Method (common)
Replay of round17B/<sid> (and its o/d/x variants) with harness5.js; R17 model answers reused where the prompt's key blocks were unchanged (raw prompt diff vs R17, ignoring the two global additions: «# گزارشِ وضع (همهٔ نوبت‌ها)» and, where no formula was involved, «# فرمول»). New answers were written where the round-18 rules ask for something: coach_state fields filled only when the user's own message contains them (guess / register / defer / plan / check), formulas in `$…$` when the «# فرمول» line was present and the reply contained a formula, the 🔭 offer-only modality (s17, s19). Formula inputs added where a real user would type them (s11 chat + step field, s17 chat, s18 chat). Every scenario ends with {"exit":true} (before/after shots of «🧠 کارنامهٔ ذهن», «🗺 نقشه‌ها», «امروز» exist in out/view_pre_* / view_post_*). After the run the profiles were opened again read-only to dump session state (coach.reg/guess/checkRep, plans, promises, m.guess) and the mind card text. strict.py (more than one unmarked question directive) on every prompt: clean. RC3 scan (any line that both offers and orders live_new): clean.
