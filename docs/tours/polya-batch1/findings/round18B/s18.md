Formula inputs added where a real user would type them (s11 chat + step field, s17 chat, s18 chat). Every scenario ends with {"exit":true} (before/after shots of «🧠 کارنامهٔ ذهن», «🗺 نقشه‌ها», «امروز» exist in out/view_pre_* / view_post_*). After the run the profiles were opened again read-only to dump session state (coach.reg/guess/checkRep, plans, promises, m.guess) and the mind card text. strict.py (more than one unmarked question directive) on every prompt: clean. RC3 scan (any line that both offers and orders live_new): clean.
