# بایگانیِ دستورهای ناظر

هر بار که `PROMPT.md` یا `URGENT_PROMPT.md` تغییر می‌کند، نسخهٔ قبلی **پیش از ویرایش** این‌جا
کپی می‌شود با نامِ `PROMPT-v{N}-{YYYY-MM-DD}.md` / `URGENT_PROMPT-v{N}-{YYYY-MM-DD}.md`، و یک خط
زیرِ همین فایل می‌گوید چرا نسخه عوض شد. این فایل‌ها هرگز ویرایش یا حذف نمی‌شوند.

روالِ کامل: [`../README.md`](../README.md) › «چطور دستورِ ناظر را عوض کنم؟».

- `PROMPT-v1-2026-10-08.md` و `URGENT_PROMPT-v1-2026-10-08.md` — پیش از v2: فایل‌ها و تصویرها به
  پوشهٔ درایوِ هر گزارش (`LifeManagerData/inspection/report-NNNN`) با رفرنس و md5؛ `file` مانده‌های
  پایگاه‌داده را هر دور منتقل می‌کند؛ هیچ تغییری در درایو جز از راهِ برنامه.

- `PROMPT-v2-2026-10-08.md` و `URGENT_PROMPT-v2-2026-10-08.md` — پیش از v3: پیوستِ HTML ای که باید صفحه شود
  با `install-app` «صفحهٔ افزوده» می‌شود (داده)، نه کپی در ریپو — بررسیِ ایمنی آن را همیشه رد می‌کرد.

- `PROMPT-v3-2026-10-08.md` و `URGENT_PROMPT-v3-2026-10-08.md` — پیش از v4: «هر قالبی، کامل» (صوت/ویدیو
  با رونویسیِ کامل، ZIP ِ بازشده، همهٔ قالب‌های تصویر، doc/xls/rtf/odf/epub/ایمیل) و «پیوستِ الگو را بفهم، کپی نکن».

(نسخهٔ ۱ ِ هر دو در ۲۰۲۶-۱۰-۰۸ ساخته شد — الگو: Detective-1 `PROMPT` v3 / `URGENT_PROMPT` v10 و
ALLIN1 `PROMPT` v14 / `URGENT_PROMPT` v6.)
